# RB-005: Provider Rate Limiting (HTTP 429)
## Condition
Provider API responds with HTTP 429 Too Many Requests due to temporary concurrency quotas.
## Diagnostic Criteria
- Logs report 429 with retry-after header.
- Provider status is DEGRADED.
## Prescribed Actions
1. Throttle queue dispatch; do NOT disable provider if funds are sufficient.
2. Requeue transiently throttled tickets with exponential backoff.
