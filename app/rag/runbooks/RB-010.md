# RB-010: Stale Data Snapshot Mitigation
## Condition
Action execution is requested on data snapshot older than tool TTL limits.
## Diagnostic Criteria
- `Clock.now() - tool.as_of > tool.ttl_seconds`.
## Prescribed Actions
1. Execute mandatory fresh tool re-fetch.
2. If re-fetch fails, mark proposal STALE_BLOCKED and disallow approval.
